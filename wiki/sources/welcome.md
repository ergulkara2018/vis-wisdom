The book's front matter: it states the scope ("ggplot2 mechanics + visualization wisdom"), how to read the book, and that it is an evolving teaching text.

## What it says

- **Goal:** combine ggplot2 *mechanics* (how to build plots) with visualization *wisdom* (how to make them effective) in one book, so readers get a solid grounding in ggplot2 and can build effective visualizations "for common situations". It does not try to cover every plot type or strategy.
- **Complements, not replaces,** *R for Data Science* (R4DS), the ggplot2 website and RStudio's ggplot2 cheat sheet — those cover mechanics.
- **Wisdom sources named:** William Cleveland's books and papers (*The Elements of Graphing Data*), Edward Tufte (*The Visual Display of Quantitative Information*), Claus Wilke (*Fundamentals of Data Visualization*). See [William Cleveland](../people/william-cleveland.md), [Edward Tufte](../people/edward-tufte.md), [Claus Wilke](../people/claus-wilke.md).
- **Organization:** thematic, one chapter per *category of visualization* (time series, distributions, …), each mixing mechanics and wisdom; mechanics are introduced only when a visualization task needs them. Read in order. A drawback the authors admit: the book is a poor reference for looking up mechanics (use the cheat sheet).
- **Evolving:** used since January 2019 to teach Stanford's Data Challenge Lab (DCL); student feedback drives revisions. License CC BY-NC-SA 4.0. Authors: Sara Altman, Bill Behrman.
